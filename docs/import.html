竞彩网截图导入

拖入截图 → 本地识别文字 → 你确认赔率 → 写入你的 EV 数据库

你每天只做这一件事：把中国竞彩页面截图拖进来。OCR 会先识别文字；你必须确认赔率后才会保存。OCR 可能看错小数点、队名或盘口，请不要跳过确认。

第 1 步：拖入截图

把中国竞彩截图拖到这里或点击这里，从电脑选择图片支持 JPG、PNG、WEBP。截图先在浏览器本地识别，不会直接上传原图。

第 2 步：确认赔率

OCR 只负责帮你抄写。请对照原截图逐项确认，尤其是 比赛、玩法、选择、赔率。确认错误的数据会导致 EV 计算错误。

识别到的小数赔率：尚未识别

你保存后会发生什么

  1. 确认后的中国竞彩赔率会写进你自己的 Supabase 数据库。
  2. GitHub 云端 Agent 在下一次定时运行时读取最新目标赔率，并与外部赔率、历史数据进行审计。
  3. 只有数据完整且保守 EV 达标时，报告才会出现“可投候选”；否则显示 PASS。

设置你的 Supabase 数据库连接

Project URL 和 Publishable / anon key 都是网页端公开连接信息，不是数据库密码。它们只保存在当前浏览器。不要填 service_role key，也不要填数据库密码。
